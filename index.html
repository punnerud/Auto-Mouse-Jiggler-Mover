FAQ

Good to know

Something else? Write to morten@punnerud.net.

Is it free?

Yes, it’s free to download. An optional in‑app purchase or subscription unlocks extended stop timers and some extra features. The App Store shows the price in your own currency before you buy anything.

Will it move my cursor away from what I’m doing?

No. Each move is a tiny 6‑point circle that ends exactly where it started. It pauses while you use the mouse or type, and with “Let go when I move the mouse” turned on, grabbing the mouse mid‑circle stops it at once and leaves the cursor where you put it.

Can it work without moving the cursor at all?

Yes. Set Jiggle Interval to “Never” and turn on “Use Mac API activity (Accessibility)” in Settings. The app then works through the macOS Accessibility API and the pointer does not move.

Why does it ask for Accessibility permission?

macOS only lets apps you approve move the pointer, so the app asks once in System Settings › Privacy & Security › Accessibility. You can turn it off there at any time.

Which Macs does it run on?

Any Mac with macOS 13.5 or later. It installs from the Mac App Store and lives in the menu bar, with no Dock icon.

What data does it collect?

The app collects no data and needs no account; it runs locally on your Mac. This website uses Google Analytics to count visits. Read the privacy policy.

How do I stop it?

Click the menu bar icon and choose Stop, or use Set Timer to Stop and it ends on its own. Quit is always one click away in the same menu.
